# ✨ Developer Portfolio

A modern, responsive personal portfolio website showcasing my journey as a Computer Science Engineering student, my technical skills, projects, achievements, and experience.

## 🚀 About the Project

This portfolio is being built to establish my professional presence as a Software Engineer and Full-Stack Developer.

The goal is to create an interactive and visually engaging experience with a futuristic **Dark Glassmorphism UI**, featuring translucent glass cards, ambient gradients, subtle neon effects, and smooth animations.

## 🎨 Design Highlights

- Dark futuristic aesthetic
- Transparent glassmorphism components
- Cyan, blue & purple gradient accents
- Smooth scroll-based animations
- Interactive hover effects and transitions
- Fully responsive design

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lucide React

## 📌 Development Status

🟡 **Currently in Development**

The portfolio is being developed incrementally, with each section carefully designed and implemented.

To build more than just a portfolio — an interactive digital space that reflects my technical abilities, creativity, engineering mindset, and continuous learning journey.
